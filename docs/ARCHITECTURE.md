# Архитектура и технический проект Screen Translator

## 1. Выбранный стек и обоснование

- **Платформа и язык**: C# 12 (Roslyn 5.5 / MSBuild 18.5), целевой рантайм `.NET Framework 4.8` + `Windows Runtime (WinRT 10.0.26100.0)`.
- **Пользовательский интерфейс и окна**: WPF (`PresentationFramework`, `PresentationCore`, `WindowsBase`) с кастомным `WindowChrome`, векторной иконографией и динамической сменой тем (Тёмная / Светлая), а также нативной интеграцией Win32 (`user32.dll`, `gdi32.dll`, `dwmapi.dll`, `shcore.dll`).
- **Локальное распознавание текста (OCR)**: Системный движок `Windows.Media.Ocr.OcrEngine` (работает полностью локально без отправки скриншотов в сеть, возвращает иерархию `OcrResult -> OcrLine -> OcrWord` с точными координатами `BoundingRect`).
- **Защита секретов**: Windows DPAPI (`System.Security.Cryptography.ProtectedData`, `DataProtectionScope.CurrentUser`) — ключи API никогда не сохраняются в открытом виде в `settings.json`.
- **Защита от самозахвата Overlay**: Аппаратно-композитный флаг окна `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)` (`0x00000011`) + резервное скрытие окна на время захвата, если видеодрайвер не поддерживает флаг.

## 2. Независимые компоненты

1. `ScreenCaptureService` — захват произвольной области виртуального экрана (с поддержкой нескольких мониторов и отрицательных координат), адаптивное двукратное масштабирование (`2x Bicubic`) для мелкого текста интерфейсов, анализ фона и контрастного цвета текста (`SampleRegionStyle`) под каждой распознанной строкой.
2. `TextRecognitionService` — локальный OCR через `Windows.Media.Ocr`, выбор языка или автоопределение (`en-US` / `ru` и другие системные языки), адаптивное расширение области захвата вокруг курсора (Режим A), группировка слов и строк с пересчётом физических экранных координат.
3. `TranslationService` — модульная система провайдеров перевода (`Google Translate GTX`, `MyMemory`, `DeepL API`, `OpenAI / Совместимый LLM`), пакетный построчный и полнотекстовый перевод, таймауты, `CancellationToken`, ограничение параллелизма и обработка сетевых ошибок.
4. `OverlayService` — прозрачное безрамочное окно поверх оригинала с точным позиционированием через `SetWindowPos`, исключением из захвата экрана (`WDA_EXCLUDEFROMCAPTURE`), подбором размера шрифта и цвета подложки под каждую строку оригинала, а также компактной панелью управления временным переводом (Режим C).
5. `HotkeyService` — глобальные горячие клавиши через `RegisterHotKey` (`Ctrl+Shift+T`, `Ctrl+Shift+A`, `Ctrl+Shift+H`, динамический `Esc`), проверка конфликтов и переназначение без перезапуска.
6. `TrayService` — иконка в системном трее с векторной отрисовкой состояния (Активен / Приостановлен) и тематическим контекстным меню.
7. `SettingsService` — сохранение конфигурации в `%LocalAppData%\ScreenTranslator\settings.json`, DPAPI-шифрование API-ключей, управление автозапуском Windows.
8. `TranslationCache` — потокобезопасный LRU-кэш переводов с поддержкой TTL и метриками попаданий/промахов.
9. `LoggingService` — потокобезопасное диагностическое логирование без записи распознанного текста, переводов, изображений экрана и ключей API.
