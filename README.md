# Screen Translator для Windows 10/11

Нативное настольное приложение для перевода текста непосредственно на экране поверх оригинала. Работает в фоновом режиме в системном трее, использует локальное распознавание текста (**Windows.Media.Ocr**) без отправки скриншотов на внешние серверы и отображает переведённый текст на месте исходного с помощью аппаратно исключённого из повторного захвата прозрачного слоя (**Overlay**).

---

## 1. Основные возможности

- **Три режима перевода**:
  1. **Перевод под курсором (`Ctrl + Shift + T`)** — захватывает область вокруг указателя мыши, распознаёт строки и автоматически расширяет зону поиска, если строка или абзац обрезаны по краям.
  2. **Перевод выделенной области (`Ctrl + Shift + A`)** — позволяет обвести любую прямоугольную область экрана (игры, PDF-документы, изображения, сложные интерфейсы) с поддержкой нескольких мониторов и отрицательных координат.
  3. **Управление временным переводом (`Ctrl + Shift + H` / панель над Overlay)** — быстрое переключение между переводом и оригинальным изображением, повторный перевод той же области, выбор новой области, копирование текста, режим свободного перемещения overlay и закрытие по `Esc`.
- **Визуальная подмена текста на месте (In-Place Overlay)**:
  - Анализирует пиксели вокруг каждой распознанной строки (`SampleRegionStyle`).
  - На однородных фонах (документы, браузеры, интерфейсы программ) подбирает точный цвет фона оригинала и контрастный цвет шрифта, маскируя исходный текст.
  - На сложных неоднородных фонах (игры, фотографии, градиенты) автоматически включает полупрозрачную контрастную подложку для сохранения читаемости.
  - Автоматически масштабирует размер шрифта и межстрочный интервал под габариты исходной области.
- **Защита от повторного самозахвата**:
  - Использует системный флаг окна `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)` (`0x00000011`), благодаря чему Windows исключает само окно overlay из скриншотов при повторном нажатии горячей клавиши на том же месте (с автоматическим резервным скрытием на время захвата, если видеодрайвер не поддерживает флаг).
- **Локальный OCR и модульные провайдеры перевода**:
  - Распознавание текста выполняется локально средствами `Windows.Media.Ocr` (английский, русский и другие установленные в Windows языковые пакеты) с адаптивным 2x бикубическим увеличением для мелких шрифтов.
  - Поддерживаются 4 провайдера перевода:
    1. **Google Translate (GTX)** — работает сразу после запуска, бесплатно и без API-ключа.
    2. **MyMemory Translated API** — бесплатный REST API перевода (опционально можно указать email для увеличения лимита).
    3. **DeepL API (Free / Pro)** — облачный перевод при наличии пользовательского API-ключа.
    4. **OpenAI / Совместимый LLM (OpenAI, OpenRouter, локальный Ollama)** — перевод через любую совместимую LLM-модель.
- **Безопасность и конфиденциальность**:
  - Скриншоты обрабатываются только в оперативной памяти и не сохраняются на диск.
  - Ключи API шифруются с помощью **Windows DPAPI (`ProtectedData`, `CurrentUser`)** и никогда не хранятся открытым текстом в `settings.json`.
  - В диагностические логи не записываются распознанный текст, переводы или секретные ключи.

## 2. Расположение файлов и сборка

Исходный код и готовые сборки находятся в каталоге:
`C:\Users\paraxyoz\.gemini\antigravity\scratch\screen-translator`

- **Готовый к запуску Release-файл (Portable `.exe`)**:
  - `bin\Release\ScreenTranslator.exe` (также скопирован в `dist\ScreenTranslator.exe`)
- **Установщик для Windows (`Setup .exe`)**:
  - `dist\ScreenTranslatorSetup.exe` (содержит встроенный образ приложения, создаёт ярлыки на Рабочем столе и в меню «Пуск», поддерживает тихую установку `--silent` и удаление `--uninstall`)
- **Быстрый запуск**:
  - Запустите `run.bat` или напрямую `bin\Release\ScreenTranslator.exe`.
- **Полная пересборка и запуск автотестов**:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\build.ps1
  ```

## 3. Использование и горячие клавиши

После запуска приложение появляется на экране и размещает иконку в системном трее Windows. При закрытии главного окна крестиком приложение сворачивается в системный трей и продолжает работать в фоне.

| Сочетание клавиш (по умолчанию) | Действие |
|---------------------------------|----------|
| `Ctrl + Shift + T` | Перевести текст непосредственно под курсором мыши |
| `Ctrl + Shift + A` | Выделить прямоугольную область экрана для перевода |
| `Ctrl + Shift + H` | Скрыть или повторно показать текущий перевод (Overlay) |
| `Esc` | Отменить выделение области или закрыть активный Overlay |

Все комбинации клавиш можно переназначить без перезапуска программы в разделе **«Горячие клавиши»**.

---

## 4. Настройка провайдеров перевода и API-ключей

По умолчанию выбран провайдер **Google Translate (GTX)**, который **не требует API-ключа** и работает сразу.

Если вы хотите использовать **DeepL API** или **OpenAI / совместимый LLM**:
1. Откройте главное окно и перейдите в раздел **«Перевод»**.
2. Выберите нужного провайдера в выпадающем списке.
3. Введите ваш ключ в соответствующее защищённое поле (ключ автоматически зашифруется через Windows DPAPI и сохранится в `%LocalAppData%\ScreenTranslator\settings.json`).
4. Для локального **Ollama** укажите адрес `http://localhost:11434/v1/chat/completions` и имя модели (например, `llama3.2`) — в этом случае API-ключ не требуется.
5. Нажмите кнопку **«Проверить перевод»** для проверки соединения и времени отклика.

## 5. Известные технические ограничения

1. **Визуальная подмена вместо модификации чужих процессов**: приложение отображает поверх исходного окна прозрачный экранный слой (Overlay) и не изменяет внутреннюю память или DOM сторонних программ. При прокрутке содержимого в исходном окне перевод следует обновить нажатием горячей клавиши или кнопки «Повторить» на панели overlay.
2. **Сложные фоны**: на однородном фоне цвет подложки подбирается точно под фон документа или интерфейса. На пёстрых фонах (3D-сцены в играх, фотографии, видео) идеальная бесшовная ретушь фона в реальном времени без тяжёлых GPU-моделей невозможна, поэтому приложение автоматически применяет аккуратную полупрозрачную контрастную подложку.
3. **Эксклюзивный полноэкранный режим и DRM**: игры в режиме Exclusive Fullscreen (DirectX/Vulkan), античит-драйверы и окна с аппаратной защитой контента (`WDA_MONITOR` / DRM) могут блокировать захват экрана или отображение поверх них. Для игр рекомендуется использовать режим **«Оконный без рамки» (Borderless Windowed)**.
4. **Языки локального OCR**: движок `Windows.Media.Ocr` использует языковые пакеты, установленные в системе Windows (просмотреть список установленных пакетов можно в разделе «Производительность»).
